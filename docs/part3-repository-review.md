# Как выбирались проекты для части 3

Для финального ответа я выбрал не три самых больших репозитория, а три проекта,
которые вместе лучше показывают соответствие вакансии.

## Критерии выбора

- есть работающий результат, который можно открыть или запустить;
- понятна решаемая бизнес-задача;
- видны AI-логика, API или интеграции, а не только интерфейс;
- можно проверить мою роль, технический стек и инженерную дисциплину;
- проекты дополняют друг друга, а не повторяют один сценарий.

## Почему выбраны именно они

1. **AI Lead Intake for Bitrix24** ближе всего к задачам вакансии: входящий
   бизнес-процесс, AI-классификация, прозрачная маршрутизация, CRM API и ручная
   проверка неоднозначных решений.
2. **Bitrix24 Communication Summary Agent** показывает другой рабочий процесс:
   превращение неструктурированных коммуникаций в конкретные CRM-действия с
   защитой от случайной записи.
3. **Replyline** доказывает, что я могу довести AI-идею до самостоятельного
   desktop-продукта с интерфейсом, системным аудио, STT, LLM, безопасным
   хранением ключей, тестами и релизами.

Вместе эти проекты показывают три нужные для роли стороны: автоматизацию
бизнес-процесса, интеграцию AI с рабочими системами и самостоятельную разработку
пользовательского продукта.

Остальные проекты не включены, потому что либо повторяют уже показанный сценарий,
либо требуют долгого объяснения, либо не имеют такого же простого публичного
доказательства результата.
