# Учёт фактического времени

| Часть | Фактическое время | Что вошло |
|---|---:|---|
| 1. Поиск блогеров | 6 ч | анализ Excel, исследование seed, код, тесты, кандидаты, офферы, документация |
| 2. Автоматизация процесса | 1 ч | выбор процесса, экономика по SKU, безопасный сценарий внедрения, дизайн пилота и метрика успеха |
| 3. Прошлые работы | 3 ч | аудит портфолио, выбор трёх кейсов, проверка ссылок, запуск demo-режимов, скриншоты и описание личного вклада |
| Упаковка | 2 ч | структура репозитория, CI, навигация, скриншоты и финальная проверка ссылки |
| **Итого** | **12 ч** | три части задания и общая упаковка |
